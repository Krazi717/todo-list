# To Do List

A simple task list app built with HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Remove tasks
- Tasks are saved in browser localStorage for persistence

## Usage
1. Open `index.html` in your browser.
2. Type a task into the input field.
3. Click **Add Task** or press Enter.
4. Click a task to toggle completed state.
5. Click the delete button to remove a task.

## Files
- `index.html` — page structure and layout
- `style.css` — visual styling and layout polish
- `script.js` — task management and local storage persistence
